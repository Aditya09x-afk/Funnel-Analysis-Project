---
This project presents a complete end-to-end data analytics workflow that analyzes how users move through an e-commerce purchase funnel. The goal is to identify conversion rates, drop-off points, and revenue drivers using **Python** for data analysis and **Power BI** for interactive visualization.

The project simulates real-world user activity data, performs exploratory data analysis (EDA), and builds a business-focused dashboard to generate actionable insights.

---

## 🎯 Project Objective

The objective of this project is to analyze user journeys across an e-commerce funnel and identify where users drop off before completing a purchase.

**Funnel stages analyzed:**
- Browse → Add to Cart → Checkout → Purchase

By analyzing user movement across these stages, businesses can identify conversion bottlenecks and optimize their sales funnel.

## 🔄 Project Workflow

### 1️⃣ Data Generation
- Python script generated 10,000 simulated user interactions.  
- Each session moves through funnel stages: Browse → Add to Cart → Checkout → Purchase.  
- Additional attributes: Marketing Channel, Device Type, Region, Product Category, Revenue.  
- Exported as CSV for analysis and visualization.  

### 2️⃣ Data Cleaning & Preparation
- Handled missing values  
- Standardized categorical fields  
- Verified funnel stage progression  
- Generated descriptive statistics  

### 3️⃣ Exploratory Data Analysis (EDA)
- Conducted with Matplotlib and Seaborn  
- Key analyses:  
  - Conversion rate calculations  
  - Funnel stage drop-off analysis  
  - Revenue contribution by marketing channel  
  - User distribution by device and region

## 📈 Power BI Dashboard

A 3-page interactive dashboard designed to analyze funnel performance and marketing effectiveness.

**Filters available:**
- Date Range  
- Region  
- Device Type  
- Marketing Channel  

---

## 📊 Dashboard Overview

### KPI Section
- **Total Users Entering Funnel** – Unique users who started browsing  
- **Overall Conversion Rate** – % of users completing a purchase  
- **Drop-off Rate** – Users lost during the funnel process  
- **Total Revenue** – Revenue generated from completed purchases  

### Funnel Visualization
- Funnel Chart showing progression: Browse → Add to Cart → Checkout → Purchase  
- Identifies largest drop-offs  

### Stage Drop-off Analysis
- Drop-off chart showing losses between stages:  
  - Browse → Add to Cart  
  - Add to Cart → Checkout  
  - Checkout → Purchase  

### Revenue & User Insights
- Revenue by Marketing Channel  
- Users by Device Type  
- Revenue by Region
